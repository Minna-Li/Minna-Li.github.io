实验可重复性的保证

def set_reproducibility(seed=42):
    random.seed(seed) #锁死 Python 自带的随机生成器
    os.environ['PYTHONHASHSEED'] = str(seed) #锁死 Python 内部字典和集合的哈希排序顺序
    np.random.seed(seed) #锁死 NumPy 矩阵操作中的随机性
    tf.random.set_seed(seed) #锁死 TensorFlow 图级别的随机性。这决定了神经模型每次初始化时的权重矩阵一模一样！！！
    tf.config.experimental.enable_op_determinism() # 显卡（GPU）在做卷积运算时，为了追求极致速度，默认会使用一些“非确定性”的并行算法（每次算出来的结果在小数点后很多位会有极小偏差）。这一行代码强制 GPU 放弃这种加速机制，必须老老实实地按确定顺序算，确保 100% 绝对复现

seed_value = 88 # 可以选择任何喜欢的整数
set_reproducibility(seed_value)

划分数据集

核心工具：
tf.keras.utils.image_dataset_from_directory （TF 官方的数据加载神器）
image_dataset_from_directory() : 它不会把所有图片一次性塞进内存（那样内存会爆），而是建立一个“数据管道”。当你开始训练时，它会像流水线一样，从硬盘的对应文件夹里现抓取图片、现转换成 Tensor（张量矩阵）。 此外自带 validation_split 参数，可以直接在内存中完成分层划分，缺点是每次只能划一刀。注意划分train_ds 和 val_ds时一定要设置相同的随机种子确定两次刀法一样
df.data : 流水线管理系统。首先搞清楚硬盘、cpu、gpu各自的分工，硬盘放着庞大的数据集图片，cpu从硬盘读取以及数据预处理等，随后传递给gpu做计算；你会发现如果按照这个处理顺序，当cpu在处理图片时。gpu在闲置；tf.data 就是来解决这个问题的一条数据高效流转传送带。
prefetch(num) :cpu预取数据，意味着当gpu还在处理前一组数据时。cpu不会闲置，而是提前在后台预处理下一批数据，参数num表示它每次预处理num个批次的数据。更常用的是prefetch(AUTOTUNE)。
AUTOTUNE: 是tf.data里的最伟大的发明。它是让tf根据你当前的电脑cpu核心数和内存大小，自动决定后台提前预加载多少个张量矩阵（gpu处理的是多个features组合的张量矩阵，这就是batchsize的定义）

def scale_image(image, label):
    image = tf.cast(image, tf.float32) / 255.0 # 注意必须先修改数据浮点类型为float32才能做归一化， tf.cast(原来的张量, dtype=想要的类型)， 复习：numpy里类似的功能是np.astype()
    return image, label

shuffle 打乱数据顺序

.shuffle(buffer_size, seed=None) :buffer_size 的意思是从流水线上先抓取多少个样本放进“搅局池”里。如果你的内存够大，buffer_size 最好等于你的数据集总大小（完全打乱）；如果内存不够，至少要设置一个大于你 batch_size 的数字（比如 1000），因为buffer_size越大，打乱的随机性就越强。

注意batch_size大小不会影响shuffle, 因为是先打乱再分组，shuffle先batch后，两个步骤相互独立

ds = ds.shuffle(1000)

batch 对数据分批次

.batch(batch_size, drop_remainder=False) :把零散的样本打包成批次送给显卡。
如果数据集大小不能被 batch_size 整除，最后会剩下一个小尾巴。在某些对尺寸要求极其严格的模型里，可以设置 drop_remainder=True 扔掉这个小尾巴。

cache 缓存数据（不用反复读硬盘）

作用：缓存机制。如果你在 .map() 里做了一些非常耗时的操作（比如读取大文件、复杂的解码），.cache() 可以把第一轮（Epoch 1）处理好的数据直接暂存在内存或硬盘里。到了第二轮（Epoch 2），直接从缓存拿，跳过所有计算！

注意：如果是做随机数据增强（比如每次随机裁剪），千万不要在数据增强前加 .cache()，否则你每个 Epoch 拿到的增强图像都是一模一样的。

ds = ds.cache(filename='')

prefetch CPU预取数据

ds = ds.prefetch(tf.data.AUTOTUNE)

repeat 数据重复应用

ds = ds.repeat(5)  #数据用5次

take/skip : 取部分数据

ds = ds.take(100) # 只取ds的前100个数据
ds = ds.skip(100) # 跳过ds的前100个数据，只取其剩下的数据

搭建模型

模型的搭建可以完全自定义，也可以迁移学习使用keras内部已经预训练好的模型, 位于tf.keras.applications中。注意如果是迁移学习，往往需要修改顶部分类头，使其对应你自己的分类任务。本节给出的是迁移学习使用EfficientNetB0的一个示例。

在我个人的学习认知里，从使用Sequential将网络层一层层连接搭建起来，再到模型编译（给出优化器、loss等），是一个完整的网络搭建过程。因此这一章节到model.compile()就结束了，model.fit()放在了下一节。

再深入讲讲tf的底层。事实上，在调用 model.compile 之前，模型只是一堆“静态的层”的组合，它知道数据的形状会怎么变，但它没有灵魂，不知道怎么学习。当调用 compile 时，TensorFlow 在后台做了这些极其关键的工作：

  1. 组装计算图（Computational Graph）：把网络结构、损失函数（Loss）、优化器（Optimizer）用数学公式严密地缝合在一起。
  2. 连接自动求导引擎：告诉 TF 的底层，在反向传播时，应该怎么计算 Loss 对每一个权重的偏导数（梯度）。
  3. 分配内存：为优化器所需的动量（Momentum）和历史梯度（如 Adam 优化器内部的缓存变量）预留好显存空间。
    也因此，只有经过了 compile，模型才从一个“数学公式”变成了一台真正可以启动的“学习机器”。

keras的内置预训练模型（tf.keras.applications）

这一节讲讲深度学习CV领域的发展史：

AlexNet (2012) - 深度学习的开山鼻祖

  • 解决的核心问题：证明了 “深层卷积神经网络 (CNN) + 大数据 + GPU 加速” 这条路不仅走得通，而且潜力无穷。它首次大规模使用了 ReLU 激活函数（解决了传统的 Sigmoid 函数容易导致梯度消失的问题）和 Dropout 技术（防过拟合）。

    • btw, 为什么sigmoid作激活函数容易导致梯度消失呢：
      以一个多层的DNN来说，手推一下利用链式法则求$\partial Loss/\partial w$的过程会发现，当误差反向传播到第一层时，这个梯度计算公式里包含了中间每一个激活函数的导数的累乘。试想一下sigmoid的定义，它在远离原点的位置的导数值是无限接近于0的，以及导数在0处取最大值是0.25。哪怕考虑最理想的情况，如果中间共有n个激活函数，那么梯度传播到首层的一个乘子是$0.25^n$，当网络很深时（即n很大），梯度逼近0，这就是梯度消失。

VGG 系列 (VGG16 / VGG19, 2014)

  • 诞生背景：大家发现网络越深，效果越好。牛津大学的研究团队（VGG）决定把网络做深。

  • 解决的核心问题：统一了网络设计的“乐高积木”。在此之前，卷积核有大有小（比如 11x11, 7x7）。VGG 证明了全都用最小的 3x3 卷积核堆叠，不仅参数更少，而且能提取更复杂的非线性特征。

  • 缺点：参数量太庞大，非常吃显存，现在多作为学术对比的 Baseline（基线模型）

ResNet (Residual Network 残差网络, 2015)

  • 诞生背景：由何恺明大牛提出，为了解决梯度消失（Vanishing Gradient）问题。一举横扫了当年的各项视觉大奖。

  • 解决的核心问题：通过引入残差连接 (Skip Connection) 彻底解决了梯度消失问题。它允许信号“抄近道”：如果这一层学不到好东西，就把输入直接越过这一层丢给后面（使得某层的输出变成了 F(x) + x）。这使得训练 152 层甚至上千层的网络成为可能。

  • 常用场景：ResNet50 是工业界最常用、最万金油的特征提取骨干网络（Backbone）。无论是目标检测（YOLO 系列）、图像分割还是医学影像分析，遇事不决先上一套 ResNet50 绝对没错。

MobileNet 系列 (2017+)

  • 诞生背景：网络能做深了，但随之而来的是模型太大，没法部署到手机或边缘设备上。学术界开始卷“性价比”：如何在参数最少的情况下，把准确率拉到最高。
  • 解决的核心问题：标准卷积太费算力。MobileNet 发明了“深度可分离卷积 (Depthwise Separable Convolution)”，把一次复杂的空间+通道计算，拆分成两步简单的计算。极大缩减了参数量和运算时间。
  • 常用场景：手机端、安防摄像头端、无人机等算力受限的嵌入式设备上的实时图像识别。

EfficientNet 系列 (B0 - B7, 2019)

  • 诞生背景：以前大家优化模型，要么只加深（层数），要么只加宽（通道数），要么只放大输入分辨率。Google 的研究员想：能不能同时优化这三个维度的比例？
  • 解决的核心问题：提出了一种“复合缩放方法 (Compound Scaling)”。通过一个极其优雅的数学公式，找到了深度、宽度、分辨率三者的黄金比例。
  • 常用场景：以轻量、高效闻名，提取医学图像微小病灶的能力极其出色，非常适合配合贝叶斯优化在有限算力下进行反复实验。

Transformer (2017) & BERT / GPT 系列

  • 诞生背景：原本是为了解决 NLP（自然语言处理）中 RNN/LSTM 模型无法并行计算、且容易遗忘长上下文的问题（比如翻译长难句）。
  • 解决的核心问题：抛弃了传统的序列读取架构，引入了自注意力机制 (Self-Attention)。一句话解释就是：模型在看当前词汇时，能瞬间计算出句子中所有其他词汇对当前词汇的影响权重。

2020 年，ViT (Vision Transformer) 诞生，把图片切成一个个小图块（Patch）当成“单词”喂给 Transformer，证明了在海量数据下，抛弃 CNN 也能在视觉任务上取得惊人的效果。这是目前学术界最前沿的战壕。

tf.keras.Sequential([]) 自定义拼装模型

把网络层一层层串起来，数据从上到下流转。 比如使用Sequential([])将预训练好的基础底层模型，和自定义的新增其他基础layers串起来。

常用层：

  • tf.keras.layers.GlobalAveragePooling2D() :
    卷积层提取出的特征是立体的（比如 7x7x1280 的特征图）。以前的做法是把它暴力展平成一维长条，但这会导致参数量爆炸，极易过拟合。GAP 的做法是：对每一个 7x7 的切片求一个平均值。参数量瞬间降为 0，防过拟合。

  • tf.keras.layers.Dense(dense_units,...) :
    全连接层，其背后的数学原理其实就是线性变换W*x，由于batch_size个数据是一次性作为输入传入的，所以实际是矩阵乘法x_inputs_matrix * Weight_matrix.

  • tf.keras.layers.Dropout(dropout_rate)

model.compile() 模型编译

作用：告诉模型怎么学，损失函数是谁？优化算法是什么？学的好不好如何评判？

model.compile(
    optimizer="adam",

  • optimizer : 在tf.keras.optimizers里，常用的有Adam,SGD,Adagrad,RMSProp

  • loss : 在tf.keras.losses里，注意loss（损失函数） 和 label_mode（标签模式） 之间的强制对应关系。

  • metrics : 分为分类任务和回归任务

import tensorflow as tf
from tensorflow import keras
from keras import layers, regularizers

def build_pretrained_model(hparams):
    # 1. 加载预训练的EfficientNet，不包含顶部的分类层
    base_model = tf.keras.applications.EfficientNetB0(
        input_shape=(IMG_HEIGHT, IMG_WIDTH, 3),
        include_top=False,
        weights='imagenet'
    )
    # 2. 冻结预训练模型的权重
    base_model.trainable = False
    
    # 3. 确定从哪个块开始解冻（微调）
    fine_tune_at_block = 'block5a_expand_conv'
    #  遍历所有层，解冻 fine_tune_at_block 及之后的所有层
    set_trainable = False
    for layer in base_model.layers:
        if layer.name == fine_tune_at_block:
            set_trainable = True
        if set_trainable:
            layer.trainable = True
        else:
            layer.trainable = False

    # 注意： 无论是否解冻，都应该保持 BatchNormalization 层处于冻结状态
    # isinstance(对象, 类) → 判断对象是不是这个类型
    for layer in base_model.layers:
        if isinstance(layer, layers.BatchNormalization):
            layer.trainable = False
    #     等价于：
    #     if not isinstance(layer, layers.BatchNormalization):
    #         layer.trainable = True
            
    # 动态传入参数：从hparams列表中调用.get(a,b)方法安全取参数;a存在就取a的值，a不存在就取值b
    dense_units = int(hparams.get('dense_units', 128))
    dropout_rate = hparams.get('dropout_rate', 0.5)
    l2_reg = hparams.get('l2_reg', 0.001)
    lr = hparams.get('lr', 0.0001)
    optimizer_choice = int(hparams.get('optimizer_choice', 0))
    momentum = hparams.get('momentum', 0.9)
    
    
    # 4. 在预训练模型之上，构建一个分类头
    model = tf.keras.Sequential([
        base_model,
        layers.GlobalAveragePooling2D(), # 使用全局平均池化替代Flatten，参数更少，不易过拟合
        layers.Dense(dense_units, activation='relu', kernel_regularizer=regularizers.l2(l2_reg)), # 使用更小的L2值
        layers.Dropout(dropout_rate),
        layers.Dense(4, activation='softmax') # 4个类别
    ])

   
    if optimizer_choice == 0:
        print("--- 使用 Adam 优化器 ---")
        optimizer = tf.keras.optimizers.Adam(learning_rate=lr)
    elif optimizer_choice == 1:
        print(f"--- 使用 SGD 优化器 (momentum={momentum:.3f}) ---")
        optimizer = tf.keras.optimizers.SGD(learning_rate=lr, momentum=momentum)
    elif optimizer_choice == 2:
        print("--- 使用 RMSprop 优化器 ---")
        optimizer = tf.keras.optimizers.RMSprop(learning_rate=lr)
    elif optimizer_choice ==3:
        print("--- 使用 Adagrad 优化器 ---")
        optimizer = tf.keras.optimizers.Adagrad(learning_rate=lr)
    else: # optimizer_choice == 分数
        print("--- 无法找到对应的优化器，请检查optimizer_choice value ---")
        
    
    model.compile(
        optimizer=optimizer,
        #loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=False),
        #from_logits=True 表示：模型最后一层不应用 softmax 激活函数，直接输出原始分数（logits）
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
   
    return model

model.fit() 训练模型

负责以下流程：前向传播 -> 计算 Loss -> 反向传播求梯度 -> 优化器更新权重

训练完train_ds中已经划分好的全部batches（每个batch有batch_size张图片）之后，就完成了一个epoch(轮次)的训练，而深度神经网络需要多次重复上述流程，才能找到最优权重。因此epochs就表示进行多少个完整轮次的训练。

history = model.fit(
        train_ds, # 指定训练数据集(必需参数)
         # 验证数据集(可选参数)在每个epoch结束后，模型会在这个数据集上评估性能,这里因为设置了早停回调器，因此实际上是必选参数
        validation_data=val_ds,
        epochs=30, # 遍历训练数据的总轮次(必需参数)
        verbose=0,#日志显示模式,设置为0时,通常是因为使用了自定义回调函数来显示更详细的信息
        callbacks=[early_stopping_callback]
    )

训练结束（跑完全部30个epoch之后），需要对模型进行最终的测算，比如在val_ds上返回的结果loss,accuracy：

# 让模型在验证集 val_ds 上再完整跑一遍，并返回最终的成绩
loss, accuracy = model.evaluate(val_ds, verbose=0)

❓这里为什么要再在val_ds上评估一次呢？按照前面model.fit()中我们已经选择了validation_data这个参数，那么实际上每一个epoch结束模型就已经在val_ds上评估了，早停机制不是已经记录了历史最高分吗？直接把那个分数 return 回去不就行了？

解答这个问题，需要了解什么是回调器（callbacks），见下一节。

tf.keras.callbacks 训练动态分析（回调函数）

默认情况下，model.fit 是一个“黑盒”，一旦运行，除非跑完设定的 epochs，否则很难人为干预。而 Callbacks 提供了一系列的干预节点，允许我们在训练的各个特定生命周期节点（比如每个 batch 开始时、每个 epoch 结束时）强行介入，执行你想要的操作。除了上面的 EarlyStopping，常用的还有 ModelCheckpoint（自动保存模型硬盘文件）和 ReduceLROnPlateau（遇到瓶颈自动降低学习率）。

💡先回答上一节最后的问题：

# 这个定义块实际上是置于model.fit()之前的
early_stopping_callback = tf.keras.callbacks.EarlyStopping(
        monitor='val_accuracy', # 衡量指标
        patience=5,  # 验证集准确率连续5个epoch没有提升就停止
        min_delta=0.005,
        restore_best_weights=True, # 关键：自动恢复到性能最好的那个epoch的权重
        verbose=0 # 在epoch循环中保持安静
    )

这里面隐藏着一个非常优雅的代码闭环逻辑，也是你代码里 restore_best_weights=True 真正发威的地方：假设模型跑了 20 个 epoch，其中第 15 个 epoch 的 val_accuracy 最高（比如 0.985）。第 16-20 个 epoch 模型开始变笨，准确率下降。由于 patience=5，模型在第 20 轮被早停强制掐断。因为我设置了 restore_best_weights=True，TensorFlow 会在掐断的瞬间，施展“时光倒流”，把模型的权重替换回第 15 轮那个最聪明的状态！此时，model 已经是巅峰状态的身体了。但贝叶斯优化器还在外面等着要一个最终确切的跑分（即目标函数 $g(h)$ 的返回值）。于是，需要用巅峰状态的模型，再跑一次 model.evaluate(val_ds)，拿到绝对精确的最优解 accuracy，并将这个值 return 给外层的贝叶斯优化器。

完整代码：

def train_and_evaluate_model(hparams,train_ds,val_ds,epochs=30):
    model = build_pretrained_model(hparams) 
    early_stopping_callback = tf.keras.callbacks.EarlyStopping(
        monitor='val_accuracy',
        patience=5,  
        min_delta=0.005,
        restore_best_weights=True,
        verbose=0 
    )

    history = model.fit(
        train_ds,
        validation_data=val_ds,
        epochs=epochs,
        verbose=0,
        callbacks=[early_stopping_callback]
    )

    loss, accuracy = model.evaluate(val_ds, verbose=0)
    best_epoch_num = early_stopping_callback.best_epoch + 1
    print(f"  > 训练评估完成: Best Val Acc: {accuracy:.4f}, 对应的 Loss:{loss:.4f}(at epoch {best_epoch_num})")
    
    return accuracy

TF核心的四大回调函数介绍

ModelCheckpoint ：游戏自动存档机制

当训练一个庞大的模型需要长时间运行时，如果过程中突然断电，没有存档的话，前面的运行时间将彻底白费。

  • 作用：在训练过程中按照一定频率自动把模型（或权重）保存到硬盘上。
checkpoint_cb = tf.keras.callbacks.ModelCheckpoint(
    filepath='best_model.h5', # 保存的文件路径
    monitor='val_accuracy',   # 盯着验证集准确率
    save_best_only=True,      # 核心参数：只有当这次的成绩打破历史最高分时，才覆盖保存！
    save_weights_only=False   # False表示连带网络结构一起存，True表示只存权重字典
)

ReduceLROnPlateau：只能调控学习率

  • 作用：当监控的指标（如验证集 Loss）在几个 epoch 内都没有下降时，自动把学习率（Learning Rate）调小，让模型迈着更细碎的步子去寻找最优解。
lr_scheduler = tf.keras.callbacks.ReduceLROnPlateau(
    monitor='val_loss', 
    factor=0.1,   # 核心参数：每次触发时，学习率乘以 0.1（即缩小 10 倍）
    patience=3,   # 容忍度：如果连续 3 个 epoch 没进步，就触发降速
    min_lr=1e-6   # 学习率的底线，不能无限小下去
)

EarlyStopping : 早停监测器

防止过拟合（Overfitting），并节省宝贵的 GPU 算力。永远记得开启 restore_best_weights=True!

TensorBoard

作用：将训练过程中的 Loss 曲线、Accuracy 曲线、甚至是每一层网络权重的直方图分布，全部记录并渲染成极其漂亮的交互式网页图表。

tensorboard_cb = tf.keras.callbacks.TensorBoard(
    log_dir='./logs',        # 日志保存的文件夹
    histogram_freq=1,        # 每隔 1 个 epoch 记录一次权重和梯度的直方图
    write_images=False       # 是否将模型权重作为图片可视化
)

自定义回调

在 TF 中，如果你觉得自带的工具不够用（比如你想在模型准确率突破 99% 时，自动给你发一封微信通知邮件），你可以继承 tf.keras.callbacks.Callback 自己写一个：

class MyCustomCallback(tf.keras.callbacks.Callback):
    def on_epoch_end(self, epoch, logs=None):
        # 这个方法会在每个 epoch 结束的瞬间被 TF 自动触发
        if logs.get('val_accuracy') > 0.99:
            print(f"\n🎉 帅呆了！Epoch {epoch+1} 准确率破 99% 啦！")
            self.model.stop_training = True # 手动强行中止训练

贝叶斯优化器

先附上自定义的这个贝叶斯类的完整代码：

import numpy as np

class BayesianOptimizer:
    def __init__(self,search_space,init_points=5,log_file="HMC_bo_log.json"):
        self.search_space = np.array(search_space)
        self.dim = len(search_space)
        self.theta_dim = self.dim + 2 
        self.init_points = init_points
        self.log_file=log_file

        # 初始化观测点集合
        self.X_obs=np.zeros((0,self.dim))
        self.y_obs=np.zeros(0)

        # 清空内存中同命名的旧日志文件
        if os.path.exists(self.log_file):
            os.remove(self.log_file)
        
        # HMC采样时的必需参数
        self.num_samples=20
        self.burn_in=100

    def random_sample(self):
        return np.array([np.random.uniform(low, high) for (low, high) in self.search_space])
    
    def _write_log(self,iteration,x_new,y_new):
        param_names=['lr','dense_units','dropout_rate','l2_reg','optimizer_choice','momentum']
        params_dict={name:val for name,val in zip(param_names,x_new)}
        log_entry={'iteration':int(iteration),'accuracy':float(y_new),'params':params_dict}
        with open(self.log_file,'a') as f:
            f.write(json.dumps(log_entry)+'\n')
        
    # 实现HMC采样选出self.num_samples个theta
    # 流程：先计算theta后验分布，通过假设theta的先验是均匀分布，从而等价于p(y|x,theta)，而这需要先算出协方差核
    def matern52_kernel(self,X1,X2,theta):
        X1=tf.cast(X1,dtype=tf.float64)
        X2=tf.cast(X2,dtype=tf.float64)
        theta=tf.cast(theta,dtype=tf.float64)
        length_scale=theta[:self.dim]
        amplitude=theta[self.dim]
        X1_scaled=X1/length_scale
        X2_scaled=X2/length_scale
        # 计算距离矩阵的平方时，分成三部分：|X1|**2 -2*X1*X2.T +|X2|**2, 注意广播机制中1的处理，通过keepdims参数控制
        term1=tf.reduce_sum(tf.square(X1_scaled),axis=1,keepdims=True)
        # term2=-2*X1_scaled@X2_scaled.T tf张量无.T属性
        term2 = -2 * X1_scaled @ tf.transpose(X2_scaled)
        term3=tf.reduce_sum(tf.square(X2_scaled),axis=1,keepdims=False)
        r2=term1+term2+term3
        #防止距离矩阵中元素出现负数
        r2=tf.maximum(r2,1e-12)
        r=tf.sqrt(r2)
        # 求协方差核矩阵，注意tf严格限制张量乘法的张量dtype必须一致,python原生数可以和张量运算通过
        five_64 = tf.constant(5.0, dtype=tf.float64)
        sqrt_5=tf.sqrt(five_64)
        term=(1.0+sqrt_5*r+(5.0/3.0)*r2)*tf.exp(-sqrt_5*r)
        K=amplitude**2*term
        return K


    def log_posterior(self,theta,X,y):
        X=tf.cast(X,dtype=tf.float64)
        y=tf.cast(y,dtype=tf.float64)
        theta=tf.cast(theta,dtype=tf.float64)
        noise=theta[self.dim+1]**2
        K=self.matern52_kernel(X, X, theta)
        n = tf.shape(K)[0]
        n_64 = tf.cast(n, tf.float64)
        
        K+=(noise+ 1e-6)*tf.eye(n,dtype=tf.float64)
        # 计算inv(K)时采用choleskey分解,令alpha=inv(K)@y
        L=tf.linalg.cholesky(K)
        alpha=tf.linalg.cholesky_solve(L,tf.expand_dims(y,1))
        log_lik=tf.squeeze(-0.5*tf.expand_dims(y, 0)@alpha)
        log_lik-=tf.reduce_sum(tf.math.log(tf.linalg.diag_part(L)))
        pi_const = tf.constant(2 * np.pi, dtype=tf.float64)
        log_lik-=0.5 * n_64 * tf.math.log(pi_const)

        return log_lik

    def sample_theta_posterior(self):
        def target_fn(theta):
            return self.log_posterior(theta,self.X_obs,self.y_obs)
        kernel=tfp.mcmc.HamiltonianMonteCarlo(
            target_log_prob_fn=target_fn,
            num_leapfrog_steps=3,
            step_size=0.1)
        
        samples=tfp.mcmc.sample_chain(
            num_results=self.num_samples,
            current_state=tf.ones(self.theta_dim, dtype=tf.float64),
            kernel=kernel,
            num_burnin_steps=self.burn_in,
            trace_fn=None)
        return samples.numpy()

    def expected_improvement(self,x_candidate,theta_samples):
        if self.y_obs.size == 0: return 1.0
        
        y_best = np.max(self.y_obs)
        x_candidate_reshaped = x_candidate.reshape(1, -1)
        
        ei_values = []
        for theta in theta_samples:
            try:
                # 将theta转为numpy，因为下面的计算在numpy中进行
                theta_np = theta.numpy() if hasattr(theta, 'numpy') else theta
                
                K_obs = self.matern52_kernel(self.X_obs, self.X_obs, theta_np).numpy()
                noise = theta_np[self.dim + 1]**2
                K_obs += (noise + 1e-6) * np.eye(len(self.X_obs))
                
                K_cross = self.matern52_kernel(self.X_obs, x_candidate_reshaped, theta_np).numpy()
                K_candidate = self.matern52_kernel(x_candidate_reshaped, x_candidate_reshaped, theta_np).numpy()
                L = np.linalg.cholesky(K_obs)
                L_inv_K_cross = np.linalg.solve(L, K_cross)
                
                mu = np.dot(L_inv_K_cross.T, np.linalg.solve(L, self.y_obs))
                sigma2 = K_candidate - np.dot(L_inv_K_cross.T, L_inv_K_cross)

                #将 mu 和 sigma2 转换为标量
                # mu 是 (1,) 形状的一维数组, 用 [0] 提取
                mu_scalar = mu[0]
                # sigma2 是 (1,1) 形状的二维数组, 用 [0,0] 提取
                sigma2_scalar = sigma2[0, 0]
                
                sigma = np.sqrt(np.maximum(sigma2_scalar, 1e-9))
                # 如果 sigma 过小，则此点没有不确定性，EI为0
                if sigma == 0.0:
                    continue

                z = (mu_scalar - y_best - self.exploration) / sigma
                
                norm = stats.norm(loc=0, scale=1)
                ei = (mu_scalar - y_best - self.exploration) * norm.cdf(z) + sigma * norm.pdf(z)
                
                # 确保 ei 是一个正常的浮点数
                if not np.isnan(ei):
                    ei_values.append(ei)

            except np.linalg.LinAlgError:
                # 矩阵计算出错时跳过此样本
                print("警告: 在EI计算中发生矩阵奇异值错误，跳过此theta样本。")
                continue
                
        return np.mean(ei_values) if ei_values else 0.0



    def optimize(self,objective_fn,n_iter=30):
        '''主循环部分，分为两个部分，随机探索阶段和HMC BO探索阶段'''
        print(f"随机探索阶段，初始随机点数设置为{self.init_points}个")
        for i in range(self.init_points):
            x_new=self.random_sample()
            y_new=objective_fn(x_new)
            self.X_obs=np.vstack([self.X_obs,x_new])
            self.y_obs=np.append(self.y_obs,y_new)
            self._write_log(iteration=i+1,x_new=x_new,y_new=y_new)

        print(f"第二阶段，将进行{n_iter}次HMC BO探索")
        for i in range(n_iter):
            # 1. 使用HMC采样得到20组参数theta
            theta_samples=self.sample_theta_posterior()
            
            # 2. 根据20个参数theta得到20个a_EI，a_EI取均值即a_BO,中间过程封装到求EI的方法中；

            best_x=None
