tensor.dtype:

  • 整数型:
    torch.uint8 无符号的八位整数（8个bit全存数值），只能存0~255的整数，所以几乎只用来存图片，因为像素值正好是0~255
    torch.int32
    torch.int64 其中torch.int64为默认的整数类型
  • 浮点型：
    torch.float161符号+5指数+10尾数
    torch.bfloat161符号+8指数+7尾数
    torch.float32 默认的浮点数据类型，1符号位+8指数位+23尾数位
    torch.float64 高精度浮点数据类型
  • 布尔型：
    torch.bool

在PyTorch里使用最广泛的就是浮点型tensor。其中torch.float32称为全精度，torch.float16/torch.bfloat16称为半精度。而bfloat16的指数位和float32指数位一致，所以能表达的数值范围一样，所以bfloat16更为常用。一般情况下模型的训练是在全精度下进行的。如果采用混合精度训练的话，会在某些计算过程中采用半精度计算。混合精度计算会节省显存占用以及提升训练速度。

GPU加速

在GPU上进行矩阵运算可以获得大幅度的加速，这也是为什么深度学习模型训练都采用GPU来进行。

首先需要检查你的环境中是否有可以使用的英伟达GPU：

torch.cuda.is_available()
"""
输出是False,则代表没有可用的GPU
"""
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

但注意：默认创建的tensor都是在CPU/内存上的（还记得创建tensor时的参数device吗？默认是=“cpu”）。有两种方法让tensor转移到GPU/显存上：

  • 创建时，设定tensor的设备为“cuda”
tensor_gpu = torch.tensor([1,2,3],device="cuda")
  • 将cpu上的tensor通过to(“cuda”)方法转移到GPU上! 推荐使用此种方法
# 前提是确定cuda可用，否则会报错
device = torch.device("cuda")
A_gpu = A_cpu.to(device) # 将tensor转移到GPU上

tensor在不同设备上的计算原则

  • Tensor 放入GPU
    使用 tensor.to('cuda') 或 tensor.cuda() 可以将一个张量（Tensor）移动到 GPU 上。此时，该张量的数据存储和计算都会在 GPU 上进行。

  • Model 放入 CUDA
    使用 model.to('cuda') 或 model.cuda() 可以将一个模型移动到 GPU 上。这实际上是将模型内部的所有可学习参数（即 Parameter，本质上是 Tensor）移动到 GPU 上。

  • 计算设备一致性
    Tensor进行计算时，参与计算的所有Tensor必须位于同一设备上。否则，PyTorch 会抛出错误。

  • 计算结果的设备归属
    运算结果的Tensor会位于参与计算Tensor所在的设备上。

计算图与自动求梯度

深度神经网路中，往往有数百亿个参数，对应的计算图规模巨大，而误差的反向传播需要对网络中所有权重求其梯度，这是非常复杂的

自动微分如何工作

  1. 记录前向轨迹：当用框架构建好网络，并输入数据进入一次前向计算时，框架内部不仅仅是在计算结果，还自动绘制了一张计算图，它记住了所有操作的顺序和依赖关系

  2. 一键反向求导：调用 loss.backward() 函数时，框架会自动利用链式法则沿着刚刚的计算图反向走一遍，从而计算出每一个参数的梯度,通过.grad属性来得到各个参数的梯度

  3. 更新模型参数： 最后优化器（比如SGD）就使用这些计算好的梯度，去更新参数，完成一次学习迭代

optimizer = torch.optim.SGD(params=model.parameters(),lr=0.01) #params="要优化的模型参数"
optimizer.step()
  1. 每次反向传播完一定要记得清空当前的梯度信息，否则梯度会不断累积
optimizer.zero_grad()
model.zero_grad()
# 上述两种效果等价，因为model中的所有参数都被optimizer管理

# 对具体的参数手动清零：（底层写法，不推荐）
w.grad.zero_()
b.grad.zero_()

一些细节

  1. 梯度总是基于当前的张量值来计算的。
    举例说明：假如计算$z=log((3x+4y)^2)$关于x,y的偏导数。第一步一定是先进行前向传播，所以需要先定义x,y的张量结构
x = torch.tensor(1.0,requires_grad=True)
y = torch.tensor(1.0, requires_grad=True)
```  
这两个张量的当前值就是 x=1.0 和 y=1.0。然后你构建了从 x,y 到 z 的计算图，最后调用 `z.backward()`,
PyTorch会自动计算 在当前的 x 和 y 取值点 (1.0,1.0)上，z 对 x 和对 y 的偏导数

2. 为什么需要 `requires_grad` = True ？
这个参数是告诉pytorch,要为这个张量构建计算图，并记住其相关所有操作，这是后续计算梯度的前提！

3. 这个设计的实用性举例
假设现在需要训练一个神经网络，我们希望迭代的是model中的参数，而不是输入数据x, 因此：
```python
model = torch.nn.Linear(10,5) # 模型参数会自动设置requires_grad=True
input_x = torch.rand(10) # 默认的default值是requires_grad=False
output = model(input_x)
loss = output.sum()

loss.backward() # 这里！只会计算model参数的梯度，不会计算input_data的梯度

Dataset的自定义写法

  1. 可以实现对路径中的原始数据集进行读取、预处理
  2. 对不同的原始数据集，可能会有针对性的预处理策略，那么我们需要自定义类，但是一定是继承自父类 torch.utils.data.Dataset ! 此外类中一定需要两个方法：
    • __len__
      它负责返回当前数据集样本的个数
    • __get_item__(idx)
      根据输入的index返回对应的样本对（张量 X, 标签 y），这是因为后续DataLoader 会自动循环调用此方法，从而把返回的(X,y)打包成batch.
# 以泰坦尼克生存项目举例：
from torch.utils.data import Dataset
import pandas as pd
class selfdefined(Dataset):
        def __init__(self,filepath): #初始化类
                super().__init__() #继承父类初始化方法
                self.filepath=filepath
                self.data=self._load_data() #只在类中使用的加载原始数据集的方法
        
        def _load_data(self):
                df = pd.read_csv(self.filepath)
                df = pd.drop(columns=["A"]) #删除不用的列
                df = pd.dropna(subset=["age"]) # dropna是删除行，这里是删除age为空的行
                df = get.dummies(df, columns=[],dtype=int) ## 进行one-hot编码

                # 此外通常还需要对各个特征做归一化处理，有时还会做特征工程
                return df
        def __len__(self):
                return len(self.data)
        
        def __getitem__(self,idx):
        features = self.data.drop(
                columns=["Survived"]).iloc[idx].values
        label = self.data["Survived"].iloc[idx]
        return torch.tensor(features, dtype=torch.float32), torch.tensor(label, dtype=torch.float32)

DataLoader

生成迭代器，其作用是把 Dataset类型 变成 数据加载器对象（能分批、打乱、循环迭代）
原本的数据像米，Dataset像电饭煲内胆，DataLoader像电饭煲

torch.utils.data.DataLoader(
        dataset, #传入打包好的数据集,注意必须是Dataset对象，如果直接是张量或元组会报错
        batchsize, 
        shuffle=True
)

完整逻辑链：

# 步骤1：把张量 → 打包成数据集（必须用 TensorDataset）
dataset = torch.utils.data.TensorDataset(x_train, y_train)

# 步骤2：把数据集 → 放进 DataLoader
train_loader = torch.utils.data.DataLoader(dataset, batch_size=20, shuffle=True)

torch.nn 模块

nn.Module

nn.Module是PyTorch中的核心组件，在PyTorch里所有的模型，或者模型内的模块，都是基于nn.Module构建的。自定义一个模型，其内部的模块必须继承自nn.Module.

nn.Module带来了以下好处：

  • 模块化构建：对于复杂的网络，你可以将它划分为多个子模块进行构建。然后将它们组合为一个复杂模型。

  • 自动管理参数：nn.Module会自动追踪模块内所有的参数，无论这些参数是嵌套在子模块中还是作为属性值直接存储在当前模块中。可以通过模块的parameters()或者named_parameters()进行查看。

  • 统一的forward方法：所有继承自nn.Module的类必须实现一个forward方法，这样各个模块之间根据组合关系对数据进行前向处理。PyTorch里的计算图和自动求梯度机制会帮助我们实现反向传播。

  • 统一的设备管理：利用nn.Module提供的.to(device)方法，可以方便的将整个模型迁移到GPU或者CPU。

  • 模型的保存和加载：nn.Module提供了标准的模型保存和加载方法。

  • 定义了模型的train和eval状态：有的模块在训练时和预测时前向传播实现是不同的，可以通过model.train()或者model.eval()统一切换本身，和内部包含的所有模块的状态。

自定义一个模型

要点：

  1. 必须继承自 nn.Module 类

  2. 必须包含 __init__ 和 forward 方法

    • forward方法： 在forward方法内，你定义数据是如何在你的模块内进行传递计算的。需要特别注意的是，forward函数定义是给PyTorch框架内部调用的，当你想调用模型的前向传播时，千万不要直接调用forward方法，你只需要直接调用model(inputs)

    • __init__ 方法中定义所有层：nn.xxx

以一个逻辑回归模型为例：

class LogisticRegressionModel(nn.Module):
        def __init__(self):
                super().__init__()
                self.linear = nn.Linear(input_dimension, 1)
        def forward(self,x):
                return torch.sigmoid(self.linear(x))

其中nn.Linear是定义一个线性回归模型。它传入两个参数，第一个是输入特征的个数，第二个是输出特征的个数。

nn内部的常用层

import torch.nn as nn # 网络层、损失函数、模型基类

nn.Conv2d(in,out,kernel_size) # 2维卷积层，处理图像数据

nn.BatchNorm2d() # 批量归一化层
nn.Dropout(p)  # 防过拟合层
nn.Sequential() # 快速堆叠网络

常用的损失函数

nn.CrossEntropyLoss() # 分类任务用的交叉熵损失函数
nn.MSELoss()  # 回归任务
nn.BCELoss()  # 二分类

nn.functional 前向传播里的「工具函数库」

  • 包括 激活、池化、卷积、损失、归一化……
  • 属于函数： 直接调用，不用定义，不存参数！
  • 注意大小写： 在__init__中定义的是层，比如nn.Linear(10, 5)等。在forward中运行的是函数，比如F.linear(x, weight, bias)

torch.optim 模块

定义优化器，传入模型的参数，并且设置固定的学习率

optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
optimizer1 = optim.Adam(model.parameters(), lr=1e-3)
optimizer2 = optim.AdamW(model.parameters(), lr=1e-3)
for epoch in range(epochs):
    for features,labels in DataLoader(myDataset, batch_size=256):
        optimizer.zero_grad() ##优化器清理管理参数的梯度值。
        loss = forward_and_compute_loss(features, labels) ##前向传播并计算loss
        loss.backward() ##loss反向传播,每个参数计算梯度
        optimizer.step() ##优化器进行参数更新

关于 optimizer.zero_grad() :每个可训练的参数都有一个关联的梯度值。每次loss的后向传播时，新计算的梯度值都会累加在原来每个参数的梯度上。直到调用 optimizer.zero_grad()，才会将这个优化器管理的参数对应的梯度值设置为0。

在每一个训练的step里：

  1. optimizer把自己管理参数的梯度值都置为0。
  2. 模型前向传播，计算loss。
  3. loss反向传播，计算出每个参数的梯度值。
    optimizer根据每个参数的梯度值，和优化器算法，学习率来更新参数。
