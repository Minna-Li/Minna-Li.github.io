JAX是什么？

JAX 是由 Google 开发的一个 Python 第三方开源计算库（就像 NumPy、SciPy 一样，通过 pip install jax 安装）

JAX = 完美兼容 NumPy 的接口 + 自动求导 (Autograd) + 底层 GPU/TPU 极速编译 (XLA)

在使用中，JAX的核心模块几乎完整复刻Numpy:

import numpy as np
import jax.numpy as jnp

# Numpy 写法：
x = np.linspace(0, 1, 100)
y = np.fft.fft(np.sin(x))

# JAX 写法（完全一样！）：
x = jnp.linspace(0, 1, 100)
y = jnp.fft.fft(jnp.sin(x))

jax的几大优势

JAX 并不是一个神经网络框架，它是一个高性能数值计算框架。在科学计算中发挥着非常高效的作用，这归功于以下函数装饰器（Decorators）：

  1. jax.grad: 终结了控制问题中需要手动计算反向伴随方程的噩梦
    JAX可以追踪所有 Numpy 操作（包括 fft, sum, mean, 四则运算），并在底层构建一张有向无环图。当调用 jax.grad 时，它会极其精确地自动计算出偏导数。
# 假设这是一个极度复杂的流体时间积分器
def compute_loss(f_control):
    w = jnp.zeros((128, 128))
    for i in range(1000):
        # 里面有一堆 FFT、对流、扩散的复杂计算...
        w = ... 
    return jnp.mean((w - w_target)**2)  # 这通常是控制问题中的J(f)

# 神奇的时刻来了，获取求梯度的函数grad J_f，只需一行代码：
gradient_function = jax.grad(compute_loss)

# 直接得到精确的梯度矩阵！
grad_matrix = gradient_function(f_control_initial)
  1. jax.vmap: 自动向量化和批处理工具
    假如在某个随机问题中需要求解50个随机样本下的方程，如果用标准的python写法，是通过for i in range(50):，然后把流体方程解 50 遍。在 Python 里跑 for 循环是极其缓慢的。

JAX 的做法： vmap (Vectorizing Map) 可以在底层自动把单样本函数扩展成多样本的矩阵并行计算。

# 原始的解一个样本的函数
loss = single_forward_loss(f_control, single_f_stoch)

# 用 vmap 包装一下，告诉它 f_stoch 是一个批量维度 (假设形状是 50x128x128)
batch_loss_function = jax.vmap(single_forward_loss, in_axes=(None, 0))

# 现在，它会自动在底层并行解 50 个 PDE，完全不需要写 for 循环！
losses = batch_loss_function(f_control, batch_f_stoch)
  1. jax.jit: 即时编译引擎
    Python 是一门解释型语言，每一行代码都要翻译一次，这导致它算科学计算很慢。

JAX 的做法： jit (Just-In-Time) 会把您的 jax.numpy 代码“冻结”起来，然后交给底层的 XLA 编译器。XLA 会把所有冗余的内存读写优化掉，直接编译成高度优化的 C++ / GPU 机器码。

# 只要在您的主函数上加一个装饰器
@jax.jit
def my_super_fast_pde_solver(x):
    # ...

JAX与NumPy的区别

  1. 数组不可变
    在 Numpy 中可以这样写：A[0, 0] = 5.0。
    在 JAX 中会报错！必须使用 .at[].set() 语法：
# JAX 中的正确写法
A = A.at[0, 0].set(5.0)
  1. 随机数的生成方式不同
    JAX 的随机数需要显式传递状态（PRNG Key），不能像 np.random.randn() 那样随叫随到。不过在PDE求解中，随机场可以在最开头用 numpy 生成后传给 JAX 的，这样就完美规避了这个问题。

用JAX计算一个随机最优控制问题时的常用代码

空间谱方法离散

  1. 生成离散傅里叶变换的频率坐标
'''输入参数n,d:
n：信号长度，这通常等于物理空间网格剖分数量N
d：网格步长
对应的输出是freq[k]=k/(n*d)'''
kx = jnp.fft.fftfreq(N, d=config.Lx/N) * 2 * jnp.pi
ky = jnp.fft.fftfreq(N, d=config.Ly/N) * 2 * jnp.pi
self.kx, self.ky = jnp.meshgrid(kx, ky, indexing='ij')
# -Laplace的傅里叶形态
self.ksq = self.kx**2 + self.ky**2
# 将矩阵左上角的零元素替换，注意ksq是jnp数据，不能直接赋值替换！要用where这种函数式方式生成新数组
self.ksq_safe = jnp.where(self.ksq == 0, 1.0, self.ksq)
  1. 指数运算
self.E_full = jnp.exp(self.L_p * self.dt)
  1. 创建数组
self.w_target = jnp.array(generate_target_vorticity(N, config.Lx, config.Ly))
# 初始化全零矩阵
w_hat_init = jnp.zeros((self.N, self.N), dtype=jnp.complex128)

jax.lax控制流

JAX 最底层、最核心的原语操作库，相当于 JAX 的 “汇编语言”，提供了可被 JIT 编译、自动微分、向量化与并行化的基础算子与控制流。

  • 底层原语集：jax.numpy（jnp）的所有函数本质上都是 jax.lax 更高级的封装
  • XLA 薄包装：几乎所有 lax 算子都直接对应 XLA 编译器的底层指令，确保能高效编译到 CPU/GPU/TPU
  • 函数式、不可变：所有操作无副作用、不原地修改，符合 JAX 函数式编程范式
  • JIT / 自动微分友好：只有 lax 原语能被 jit、grad、vmap 等 JAX 变换正确追踪与优化

常用功能

控制流（JIT 中必须用 lax，不能用 Python 原生 for/while/if）
Python 原生循环 / 条件在 @jax.jit 中无法被编译，必须用 lax 控制流：

  • lax.fori_loop : 带索引的编译型 for 循环
# 等价 for i in range(10): x = x+i
x = lax.fori_loop(0, 10, lambda i,x: x+i, init_val=0)

  • lax.while_loop : 编译型while循环

  • lax.cond : 编译型三元 / 条件分支（if/else）

  • lax.scan : 高效序列循环！pde时间步进计算

# 对序列 carry = f(carry, x_t) 循环，记录所有中间态
final_state, all_outputs = lax.scan(
    f,        # 循环体函数（一步迭代）
    init,     # 初始状态（比如 w_hat_init）
    xs,       # 输入序列（如果没有就写 None）
    length    # 循环多少次（当 xs=None 时必须写）
)

# 具体举例
w_hat_final, _ = lax.scan(step_fn, w_hat_init, None, length=self.steps)

jax.vmap 批处理/并行运算(Vectorizing Map)

作用：自动把 “单样本函数” 变成 “批量处理函数”
不用改循环、不用改维度、自动批处理！

from jax import lax, vmap
# 假设有一个函数
def f(x):        # 输入：单个 x，形状 () 或 (C,)
    return x * 2 # 输出：单个结果

# 如何同时处理100个输入x:
x_batch.shape = (100, ...)   # 第 0 维是 batch
# 不用写 for 循环！直接用 vmap 包装函数：
f_batch = jax.vmap(f)
y_batch = f_batch(x_batch)

# 完整语法
jax.vmap(
    fun,              # 需要向量化的函数（必填）
    in_axes=0,        # 输入数据哪一维是作为 batch 维度（默认：第0维是batch）
    out_axes=0        # 输出的 batch 维放哪里（默认：放第0维）
)

jax.value_and_grad : 一次同时算 【损失值】 + 【梯度】

比单独算 loss、再算 grad 快一倍，是 JAX 训练必备函数，可以用jit！

# 普通写法
loss = loss_fn(params, x, y)
grads = jax.grad(loss_fn)(params, x, y)

# 用 value_and_grad只需要计算一次loss
loss, grads = jax.value_and_grad(loss_fn)(params, x, y)

# 完整语法
value_and_grad(
    fun,        # 损失函数（必须输出标量：单个float）
    argnums=0   # 对【哪个参数】求导
)

jax.jit : Just-In-Time 即时编译

作用：把Python 代码 → 编译成 GPU/TPU 超快机器码, 没有 jit，普通的JAX 代码和 NumPy 差不多快；加了 jit，才能让计算速度起飞，科学计算 / 训练必备！

在 PDE 数值模拟里，只需要把【最内层、被疯狂循环调用】的那一步 JIT 一次就够了。
其他函数不用 JIT，也不应该随便 JIT。 因为编译本身很慢（第一次调用要等），但编译完之后调用极快。

# 以一个普通函数举例，便于直观理解
def f(x):
    return x ** 2 + jnp.sin(x) * 3
# Python 会一步一步慢慢算。
# 如果加@jax.jit，JAX 会把整个函数编译成一个高速块，直接在 GPU 上跑，不再逐行解释。
@jax.jit
def f(x):
    return x ** 2 + jnp.sin(x) * 3

这里一定要注意前面提到过的lax块内容，要想使用jit,函数内部不能用 Python 控制流! 必须先转为lax控制流,这里稍作review

  • jax.lax.cond (代替 if)
  • jax.lax.fori_loop / jax.lax.scan (代替 for)
# 实践用法：把 “算损失 + 算梯度” 整个流程一次性编译成机器码
self.loss_and_grad_jit = jit(value_and_grad(total_objective, argnums=0))
# 上述是先把计算流程编译成机器码，具体使用时直接调用：
loss, grad = self.loss_and_grad_jit(f_jnp, samples_jnp) # 输入是total_objective的两个参数：f_control和f_stoch_batch
