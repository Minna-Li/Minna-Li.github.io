verl 框架下离线数据集处理与 RL 训练配置教程

本教程总结了在服务器网络有限/受限环境下，从环境搭建、框架安装、模型与数据集下载，到最终配置启动训练的全流程。

一、 配置 Conda 虚拟环境

目的：为 RL 训练创建一个独立的 Python 环境，避免与其他项目的依赖包发生冲突。

1. 检查 Conda 是否可用

在终端输入以下命令查看 Conda 版本：

conda --version

作用：确认系统已安装 Conda。如果正常显示版本号（如 conda 23.x.x），说明可直接使用。

2. 创建 Python 3.12 虚拟环境

conda create -n verl_env_lm python=3.12 -y

我在服务器内网受限情况下，服务器根目录安装完整环境报硬盘超限的情况下，选择了网盘work下绝对路径安装：

conda create --prefix /home/ma-user/work/conda_envs/verl_env_lm python=3.12 -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/ -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/ --override-channels -y

作用：-c 表示下载的镜像源通道。不知道为何我必须加上–override-channels（覆盖/忽略默认镜像源）才能成功下载环境

如果创建失败或者需要删除之后再重新下载：

conda remove -n rl_env --all -y  
conda remove -n verl_env_lm --all -y
pip cache purge
rm -rf /home/ma-user/work/conda_envs/verl_env_lm

3. 激活虚拟环境

conda activate verl_env_lm  # 如果直接下载在硬盘
conda activate /home/ma-user/work/conda_envs/verl_env_lm  # 如果是按前面的绝对路径下载在网盘中

作用：切换到刚建好的环境中。激活成功后，命令行开头的括号会从 (base) 变成 (verl_env_lm)。

# 有时的激活是fake激活，通过验证python版本（前面创建的3.12）来判断是否真的进入了环境
python --version
# 否则先退出再重进
conda deactivate
conda activate /home/ma-user/work/conda_envs/verl_env_lm

二、 拉取并安装 verl 框架

目的：获取基于 Ray 和 vLLM 的高效 RL 强化学习训练框架，并安装其所需的底层依赖。

1. 创建项目根目录

mkdir -p /home/ma-user/work/limin/math_rl_project
cd /home/ma-user/work/limin/math_rl_project

参数解释：

  • mkdir -p：递归创建文件夹（如果父级路径不存在会自动创建）。
  • cd：进入工作目录。

2. 克隆 verl 官方代码仓库

# 使用 git clone 命令从 GitHub 获取项目的完整代码
git clone --depth 1 https://github.com/volcengine/verl.git
# 如果遇到内网防火墙的SSL证书拦截
git clone -c http.sslVerify=false --depth 1 https://github.com/volcengine/verl.git
# 进入该文件夹（当前已经通过第一步处于/home/ma-user/work/limin/math_rl_project这个位置）
cd verl

作用：

  • 将 verl 框架的代码整包下载到当前目录下。框架代码相当于工程图纸，接下来还需要准备建筑材料（环境中的各种包）

参数解释:

  • --depth 1: 表示只下载最新版本的代码，不下载历史记录
  • http.sslVerify=false: 告诉Git在拉取代码时忽略证书验证

三、 下载基座大语言模型

  • 目的：强化学习训练（如 GRPO/PPO）需要在已具备一定基础能力的预训练模型上进行，因此先将模型权重下载到本地。
  • 途径: 从Huggingface(国外源，需要走国内镜像) or 从modelscope(国内源)。这里以后者为例

以上方式我遇到了SSL证书拦截，通过使用以下download.py成功：

import urllib3
import requests

# 1. 禁用 SSL 警告提示
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

# 2. 核心破解：强行给 requests 所有请求加上 verify=False
old_request = requests.Session.request
def unsafe_request(self, method, url, **kwargs):
    kwargs['verify'] = False
    return old_request(self, method, url, **kwargs)
requests.Session.request = unsafe_request

# 3. 开始下载模型
from modelscope import snapshot_download

print("开始连接 ModelScope 极速下载...")
snapshot_download('Qwen/Qwen3-8B', local_dir=r'D:\models\Qwen3-8B')
print("🎉 下载完成！")

然后在终端运行 py download.py 即可

脚本prepare_aime.py内容如下：

import argparse
import os
import datasets

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    # 1. 默认保存路径：processed_AIME 目录
    parser.add_argument(
        "--local_save_dir", 
        default="/home/ma-user/work/limin/math_rl_project/data/processed_AIME", 
        help="The save directory"
    )
    # 2. 默认本地原始数据路径：AIME_raw 目录
    parser.add_argument(
        "--local_data_path", 
        default="/home/ma-user/work/limin/math_rl_project/data/AIME_raw", 
        help="The local raw dataset directory"
    )
    args = parser.parse_args()

    # 声明数据源名称 (给 verl 内部做标记用)
    data_source = "aime"

    # 直接从本地文件夹读取数据（纯本地加载，不走任何网络）
    print(f"正在从本地读取数据集: {args.local_data_path} ...")
    raw_dataset = datasets.load_dataset(args.local_data_path)
    
    # 自动获取本地数据集中的 split 切片（通常为 'train'）
    split_key = list(raw_dataset.keys())[0]
    dataset = raw_dataset[split_key]

    def make_map_fn(split):
        def process_fn(example, idx):
            # 提取问题和答案。AIME 数据集的真实列名是 'problem' 和 'answer'
            question = example.get('problem') or example.get('question')
            solution = example.get('answer') or example.get('solution')
            
            data = {
                "data_source": data_source,
                "prompt": [{
                    "role": "user",
                    "content": str(question)
                }],
                "ability": "math",
                "reward_model": {
                    "style": "rule",
                    "ground_truth": str(solution)
                },
                "extra_info": {
                    'split': split,
                    'index': idx
                }
            }
            return data
        return process_fn

    # 开始数据清洗转换
    print("正在把数据翻译成 verl 专属的 parquet 格式...")
    processed_dataset = dataset.map(function=make_map_fn("test"), with_indices=True)

    # 移除原始无用列，只保留 verl 规范字段
    keep_columns = ["data_source", "prompt", "ability", "reward_model", "extra_info"]
    remove_columns = [col for col in processed_dataset.column_names if col not in keep_columns]
    processed_dataset = processed_dataset.remove_columns(remove_columns)

    # 保存结果为 test.parquet（用于评估测试）
    local_save_dir = os.path.expanduser(args.local_save_dir)
    os.makedirs(local_save_dir, exist_ok=True)
    out_file = os.path.join(local_save_dir, "test.parquet")
    
    processed_dataset.to_parquet(out_file)
    print(f"✅ 大功告成！AIME 测试集已完美转换并保存至: {out_file}")

目的：将原始 JSON/Parquet 转为 /home/ma-user/work/limin/math_rl_project/data/processed_AIME/test.parquet，供 verl 评估测试。

2. tmux 终端复用器使用指南

功能说明

tmux（Terminal Multiplexer）是一个终端复用器，允许在单个终端窗口中管理多个会话和窗格。在深度学习训练中，tmux 非常适合用于在远程服务器上长时间运行训练任务，即使断开 SSH 连接，训练也会继续在后台运行。

常用指令

指令 作用
tmux new -s <名称> 创建新的命名会话
tmux ls 列出所有会话
tmux attach -t <名称> / tmux a -t <名称> 连接到指定会话
tmux detach / Ctrl+b d 分离当前会话（后台运行）
tmux kill-session -t <名称> 终止指定会话
tmux kill-server 终止所有会话
tmux split-window 水平分割窗格（上下）
tmux split-window -h 垂直分割窗格（左右）
tmux new-window / Ctrl+b c 创建新窗口
Ctrl+b 方向键 切换窗格
Ctrl+b n 切换到下一个窗口
Ctrl+b p 切换到上一个窗口
Ctrl+b & 关闭当前窗口
Ctrl+b x 关闭当前窗格
Ctrl+b [ 进入复制模式（可滚动查看历史输出）
Ctrl+b z 当前窗格全屏/恢复
Ctrl+b 数字键 切换到对应编号的窗口

典型使用场景

在训练模型时，推荐的工作流程：

# 1. 创建训练会话
tmux new -s train

# 2. 在会话中分割窗格
#    按 Ctrl+b " 水平分割（上下两个窗格）

# 3. 上方窗格运行训练脚本
python train.py

# 4. 下方窗格启动 TensorBoard
tensorboard --logdir=logs --port=6006

# 5. 分离会话（训练继续在后台运行）
#    按 Ctrl+b d

# 6. 随时重新连接查看进度
tmux attach -t train

4. actor/grad_norm (梯度范数)
